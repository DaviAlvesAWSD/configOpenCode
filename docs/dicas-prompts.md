# Dicas de prompts econômicos (gastar menos tokens)

Guia rápido para o Mestre escrever prompts que custam menos tokens.

## Faça
- Seja específico e direto. Contexto demais = tokens demais.
- Referencie arquivos (ex.: "revisa src/app.js") em vez de colar o código inteiro.
- Use atalhos prontos: `@revisor` (revisão), `/release-notes` (releases),
  `@setup` (máquina nova), `@explica` (jorge-pet).
- Peça "aula" apenas quando quiser a explicação detalhada; sem ela, o Jorge responde curto.

## Evite
- Repetir contexto já explicado na conversa (o Jorge já tem o histórico).
- Pedir "explique tudo de novo" quando o assunto já está no contexto.
- Colar trechos grandes de código sem indicar onde estão.
