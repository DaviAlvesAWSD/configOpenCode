# Caminhos de menu e MÓDULO/ID

Mapa para montar o campo `LOCALIZAÇÃO` sem inventar informação. Cresce conforme o Mestre
confirmar os dados. Quando o produto não estiver aqui, Jorge pergunta em vez de supor.

Formato:

```
## <Produto>
- <Caminho de menu> / <Tela> — MÓDULO: <M_XXX> (ou "a confirmar")
```

---

## Saúde Pública

- Atividade Coletiva / Procedimentos Realizados / Procedimento Ambulatorial — MÓDULO: a confirmar
- Saúde Pública / Odontograma / Atendimento Odontológico — MÓDULO: a confirmar

## Faturamento

- Faturamento / Auditoria e Controle de Recursos de Glosas / Lançamentos / Glosas por Procedimento — MÓDULO: M_GLOSAS
- Faturamento / Auditoria e Controle de Recursos de Glosas / Configurações / Parâmetros — MÓDULO: M_CONFIG_FFAG

## Atendimento

- Atendimento / Central de Agendamento / Agendamentos / Geração e Liberação de Agendas — MÓDULO: M_GERA_AGENDA
